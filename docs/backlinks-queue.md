# Backlink sites queue

Free places that link to the site itself (directories, tool lists, launch sites, business and social
profiles). Separate from guest posting (docs/outreach/). The backlink researcher routine adds 10 new
sites a day; Claude submits the `ready` ones in Chrome when the owner says "listings"; sites that need
an account wait until the owner signs up (Claude never creates accounts).

Copy for every form: docs/launch/listing-kit.md. Curated software directories (AlternativeTo and similar) decline 'collections of tools': there, submit ILoveMyTools PDF Editor (/edit-pdf) as the product. Never pay, never buy a "skip the queue" or badge, never
add a fake address, never post the same link twice on one site.

**Note on today's run (2026-10-25, France + Brazil/Portugal day):** only 7 sites passed verification, not 10, and 4 of the 7 are genuinely France/Brazil-specific (short of the 6-of-10 minimum, though proportionally close). Fetching real submit pages (browser UA + curl, since several hosts return empty shells to WebFetch) worked well for Appvizer, Leptidigital, B2B Stack, Capterra, List Bulb and PeerPush, but most other candidates failed one of the skip rules: **reciprocal backlink/badge required for the free tier** (Startup Fame, LaunchIgniter, Turbo0, Dang.ai — all otherwise decent DR, but none confirmed "very high quality" enough to log as `skip (reciprocal)`); **fake-free** (Les Pépites Tech's free "Starter" tier never shows your site URL, only the paid tiers do; Digitool's pay-what-you-want didn't confirm $0 is accepted); **paid-only** (tooldirectory.ai is AI-tools-only and Stripe-checkout from the first step; Comparateur-IA.com starts at €29); **wrong fit** (G2 explicitly excludes B2C products; Framalibre and AlternativasBR only list libre/open-source or Brazilian-made software); **unreachable/down** (ShowMeYourSite 503; korben.info's "Mr Free Tools", gralon.net, 1abc.org, GoodFirms, SaaSHub, SaaSWorthy, StackShare, StartupBase.com.br and Gartner's own digital-markets.gartner.com all blocked the fetcher with Cloudflare, a 403/404, or a DNS/proxy failure); and several promising French/Brazilian leads (Maddyness, Licorne Society, ABStartups' Startup Base, Tool Advisor, Startupi's Cadastro Nacional) never surfaced a working, verifiable submission URL despite repeated searches. Recommend next run try Chrome itself (logged in) for the Cloudflare-blocked hosts, and keep hunting for more Brazil-specific directories — today found only 2 (Appvizer Brasil, B2B Stack) against 2 for France. only 8 sites passed verification, not 10, and only 4 of the 8 are genuinely Spain/LatAm-specific (short of the 6 minimum). Extensive searching (Spanish-language startup maps, national startup directories, "herramientas online gratis" lists, software-comparison marketplaces, AI-tool directories, GitHub "awesome" lists, business directories) turned up mostly: sites requiring a physical street address (skipped per rules), paid-only listings (ToolMage $69, SimilarLabs $9.99, aitoolly, SoftDoit "no se ofrece como servicio gratuito independiente"), AI-only directories with an unclear or no non-AI policy (WhatTheAI, ToolMage — both also 404/paid), dead or repurposed domains (SpainStartupMap is now a casino-review site; WebRamientas returns 503; StartupWiki/Startupeable's directory is archived since 2021), or sites with no official submission process found (Contxto, LatamList, StartupBlink and StackShare returned HTTP 403 to the fetcher). A 2026 survey cited in docs/backlinks.md already found only 21 of 341 "free" directories are actually account-free, which matches today's experience. Recommend next run try a logged-in browser session for the Cloudflare-blocked sites (StartupBlink, StackShare, GoodFirms, Capterra/GetApp network, TrustRadius) rather than the raw fetcher.

Lesson (24 Oct): never use ctrl+a then type in forms (it can type a literal "a"); set values directly or triple-click, and never press Enter in a tag field (it can submit and launch).
