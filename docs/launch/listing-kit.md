**Short description (≤ 260)**

Edit the text already in a PDF in its own font, find and replace, white out, add shapes, links and watermarks. Everything runs in your browser, so files are never uploaded. Free, no sign-up, no watermark, plus 50+ other free PDF, image and text tools.

**Long description**

ILoveMyTools is a free collection of 50+ online tools for PDFs, images, text and calculations, in 10 languages. Every file tool runs entirely in your browser with pdf.js and pdf-lib, so files are never uploaded to a server. There is no sign-up, no watermark and no daily limit.

Its Edit PDF tool changes the text that is already in a PDF: click any line and retype it, and the new wording keeps the same position, size and colour, using the PDF's own embedded font whenever it has the letters. The old wording is removed from the file rather than hidden under a white box. Find and replace works across every page, and you can white out content, add text, images, highlights, underline, strikethrough, shapes and clickable links.

Other tools include a watermark tool (text or logo, behind or on top of the content), merge, split, compress, rotate, sign, redact, protect and unlock PDF, PDF to Word, Excel and JPG, an image compressor, resizer and converter, a background remover, a word counter and calculators.

**Why I built it (maker story, ≤ 300)**

Most free PDF editors either upload your file to their servers or only let you put new text on top. I wanted one that edits the words already in the PDF, keeps its font, and never sees the file, so everything happens in the browser.
